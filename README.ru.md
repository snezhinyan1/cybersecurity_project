# Применение кибербезопасности в дисциплине "Информатика"

Добро пожаловать в репозиторий учебного проекта по кибербезопасности!
Проект показывает, как работают криптографические алгоритмы и методы информационной безопасности. Хэши, HMAC и другие базовые операции выполняет стандартная библиотека Python.

## Zero Dependencies (Ноль зависимостей)

Примеры проверены на **Python 3.14**. Для запуска достаточно стандартной библиотеки.

## Практические задачи

Проект включает **25 практических задач** с решениями на Python в папке `tasks/`. Условия и ожидаемые результаты приведены в [сборнике](TASKS.ru.md). Цель и методы работы описаны во [введении](Введение.docx).

1. **`authenticated_encryption.py`** — Учебная схема XOR + HMAC.
2. **`elliptic-curve_cryptography.py`** — Сложение точек на эллиптической кривой.
3. **`hamming_74.py`** — Помехоустойчивое кодирование (Код Хэмминга 7,4).
4. **`heuristic_analysis.py`** — Поиск участков с высокой энтропией.
5. **`merkle_tree.py`** — Дерево Меркла (Merkle Tree).
6. **`onion_routing.py`** — Луковая маршрутизация.
7. **`post-quantum_cryptography.py`** — Учебный пример задачи LWE с двумя уравнениями.
8. **`proof_of_work.py`** — Proof-of-Work на примере поиска хэша с нулями в начале.
9. **`shamirs_secret_sharing.py`** — Восстановление секрета по долям Шамира.
10. **`zero-knowledge_proof.py`** — Доказательство с нулевым разглашением (ZKP).
11. **`steganography_lsb.py`** — Стеганография (внедрение данных методом LSB).
12. **`totp_2fa.py`** — Двухфакторная аутентификация (генерация кодов TOTP).
13. **`diffie_hellman.py`** — Вычисление общего секрета по схеме Диффи-Хеллмана.
14. **`pbkdf2_hashing.py`** — Хэширование паролей с солью на базе стандарта PBKDF2.
15. **`cbc_mode_xor.py`** — Имитация режима сцепления блоков шифротекста (CBC).
16. **`password_policy.py`** — Проверка учебных правил пароля.
17. **`password_generator.py`** — Генерация случайного пароля.
18. **`file_integrity.py`** — Проверка целостности файла.
19. **`hmac_authentication.py`** — Проверка документа с помощью HMAC.
20. **`access_control.py`** — Права доступа по ролям.
21. **`caesar_cipher.py`** — Шифр Цезаря.
22. **`secure_file_paths.py`** — Проверка пути к файлу.
23. **`login_rate_limit.py`** — Временная блокировка входа.
24. **`parameterized_queries.py`** — Параметризованный запрос SQLite.
25. **`data_masking.py`** — Маскировка адреса электронной почты.

## Загрузка исходного кода

Вы можете клонировать репозиторий на свой локальный компьютер с помощью консоли:

```sh
git clone https://github.com/snezhinyan1/cybersecurity_project
cd cybersecurity_project
```

## Запуск проекта

| Windows                    | Linux / macOS                   |
|----------------------------|------------------------|
| `python tasks/имя_файла.py` | `python3 tasks/имя_файла.py` |

Например, для запуска демонстрации доказательства с нулевым разглашением выполните:

```sh
python tasks/zero-knowledge_proof.py
```

## Запуск тестов

В папке проекта выполните команду:

```sh
python -m unittest discover -s tests -v
```

На Linux и macOS используйте `python3`.
